# Local Development Setup – ClincClick

## Prerequisites

- Python 3.14+ (handled inside the backend virtual environment)
- Node.js 20+
- PostgreSQL 16+ with pgAdmin 4
- Git

## PostgreSQL Setup (required)

1. Install PostgreSQL (local) and open **pgAdmin 4**.
2. Connect to the local server.
3. Right-click **Databases → Create → Database → `service_booking_db`** (owner: `postgres`).
4. Confirm connection using `postgresql://postgres:YOUR_PASSWORD@localhost:5432/service_booking_db` (port 5432).

Do **not** replace PostgreSQL with SQLite, and never commit real passwords.

## Backend (from `backend/`)

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # or source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env      # Windows
# then edit .env: DATABASE_URL, SECRET_KEY, ADMIN_* values
python -m app.db.init_db    # optional: bootstrap an admin account
alembic upgrade head        # apply migrations (creats/updates tables)
uvicorn app.main:app --reload
```

- API root: http://localhost:8000
- Swagger UI: http://localhost:8000/docs
- Health: http://localhost:8000/api/v1/health
- Database health: http://localhost:8000/api/v1/health/db
- Tests: `pytest` (run from `backend/` so settings load `.env` correctly)

## Frontend (from `frontend/`)

```bash
cd frontend
npm install
npm run dev       # http://localhost:5173
```

Production build:

```bash
npm run build     # outputs frontend/dist
npm test          # Vitest (unit/component)
npm run test:e2e  # Playwright
```

## Docker (optional)

See `docs/deployment/docker.md`. Default Docker Compose uses the host-local PostgreSQL (recommended); a containerized DB is opt-in via `--profile container-db`.

## Migrations

```bash
# from backend/ with venv active
alembic revision --autogenerate -m "description"
alembic upgrade head
alembic downgrade -1
```
Always review autogenerated migration files before applying; verify created tables in pgAdmin.
